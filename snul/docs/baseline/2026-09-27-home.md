### Corrections to the spec's estimates

The design spec (Â§2.2) and Phase 1 plan quoted **696 hex across 45 files** and
**~155 `--wl-*` usages**. Both were wrong, and both undercounted:

- **696 â†’ 777.** The spec figure counted only `src/views` and `src/components`.
  The full `src` tree adds 81 more.
- **155 â†’ 3,672.** The 155 was a count of *definition sites* matched by a
  declaration regex, not usages. Real usage is 3,672 across 92 distinct tokens.

Consequence for the plan: the `--wl-*` drain is a much larger job than the plan
implied, and `HEX_LOCATION_BUDGET` must be **777**, not the 700 written in the
plan's `scripts/lib/config.mjs` sketch. Task 3 must use 777 or the budget check
fails on day one for the wrong reason.

## Hash-guaranteed files

Authoritative list and digests live in `scripts/lib/config.mjs` (created in Task 3).

`.gitattributes` marks all 12 as `-text`. This is load-bearing, not cosmetic:
`.env.development`, `.env.production` and `.env.test` contain CRLF line endings,
so under the default `* text=auto eol=lf` rule git normalises them to LF on the
next checkout and every recorded digest silently becomes invalid. Verified by a
forced `git checkout` round-trip that preserved all digests byte-for-byte.

### Limitations â€” read before relying on these

These are **reference captures, not a pixel-diff harness.** Being explicit about
what they cannot do:

1. **No automated image diffing exists.** No pixelmatch/jest-image-snapshot
   dependency is installed. Comparison is manual and by eye.
2. **Scroll position is not controlled.** Some captures landed mid-scroll, so
   they are not reproducible frame-for-frame on re-capture.
3. **`home-ar-1440.png` is a full-page capture** while the rest are viewport-only,
   so it is not directly comparable to the others.
4. **No mobile captures.** The browser refused a 390x844 resize
   (`Restore window to normal state before setting content size`).
5. **No admin, provider or RFQ screens.** Those routes require authentication;
   the baseline was taken in guest mode with no credentials available.
6. **Backend data is live.** Counts and cards reflect whatever the configured
   gateway returned at capture time, so content shifts between captures even when
   CSS is unchanged.

**Practical guidance:** for Phase 1A/1B verification, prefer `git diff` on the
three changed stylesheets as the primary signal, and treat screenshots as a
secondary human sanity check on `home`, `categories` and `marketplace`. A CSS diff
is deterministic; a screenshot of a live site is not.
